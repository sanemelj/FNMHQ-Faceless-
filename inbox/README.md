# Inbox — klip match pou Claude edite (règ Saneme, 11 nov 2026)

1. Mete klip brit la (mp4, 6–30 s) nan `inbox/YYYY-MM-DD/` (egz. `inbox/2026-11-12/eng_cro_kane_goal.mp4`).
2. Nan `YYYY-MM-DD/NOTES.md`, ekri: match la, minit la, sa k pase, ak ki platfòm (TikTok / Facebook / YouTube Shorts).
3. Claude edite l nan ~45 min: maks 6–9 s klip + analiz (freeze, slow-mo, flèch, vwa, caption) ≥ 70% videyo a, kredi "Footage: …" nan caption an. Li parèt nan `KIT.md` kòm yon kat nòmal.

Règ: pa retire logo diffuseur la; pa poste rezime match konplè; videyo long YouTube yo PA gen klip.
Si yon platfòm voye yon reklamasyon copyright, yon strike oswa li retire yon videyo → sispann klip sou platfòm SA A touswit epi ekri `BEZWEN SANEME:` nan NOTES.md.
