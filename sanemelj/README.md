# Sanemelj posts

> ⛔ **PA POSTE — pwodiksyon Sanemelj kanpe (Saneme, 12 nov 2026).** Kai pa bezwen poste anyen nan dosye sa a jiskaske Saneme di rekòmanse.

Ready-to-post files for the **@sanemelj** page. Kept separate from the FNMHQ football files in the rest of this repo.

- One folder per posting day: `sanemelj/YYYY-MM-DD/`.
- `POSTS.md` in each folder lists every post in time order (US Central): files, platform, time, caption, pinned comment.
- File names: `Reel_N_<Mon>_<D>.mp4` + `Cover_Reel_N_<Mon>_<D>.jpg`, `Carousel_N_<Mon>_<D>_slideX.jpg` (post slides in order), `Story_N_<Mon>_<D>.jpg` (add the sticker named in POSTS.md in the empty middle).
- Reels are silent: add a trending sound in the app when posting.
- A post that is not posted on its day moves to a later day folder.
